# The evidence classes [`knw_nuseds_records()`](https://newgraphenvironment.github.io/knowledge/reference/knw_nuseds_records.md) assigns

The evidence classes
[`knw_nuseds_records()`](https://newgraphenvironment.github.io/knowledge/reference/knw_nuseds_records.md)
assigns

## Usage

``` r
knw_nuseds_kinds()
```

## Value

`character` the values of `evidence_kind`.

## Examples

``` r
knw_nuseds_kinds()
#> [1] "count"               "count_expert"        "presence_survey"    
#> [4] "presence_expert"     "presence_unrecorded" "none_observed"      
#> [7] "not_inspected"       "unknown"            
```
