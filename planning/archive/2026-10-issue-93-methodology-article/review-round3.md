## Mechanism

Each guard checks the copies its author listed, using the guard's own predicate, and treats two hand-kept lists that happen to agree as coverage. The previous rounds' defects all have this shape: the `where` list against the literal's other copies, the "unset" reading against the keys that exist, the flagged population against the population the text names. Round 2's enumeration (findings.md) has it too. It searched only the files the `where` entries already name, which is the checker's own predicate, so by construction it could not find a copy outside them (`code-check.md`, "A proxy is not the property": a sweep that shares the checker's predicate is not evidence). Where the mechanism reaches in this diff, each place checked:

1. **A flag's name standing in for its definition.** `ws50_checked` is TRUE for every full 1:50k code, including the codes the crosswalk does not know and so never compares. The article counts the flag as "the check reaches" (finding 1).
2. **The tracked/ignored split of the bundle's sources**, a hand-kept list against `.gitignore` (finding 2).
3. **The dirty check's path list** (`src_code`) against the files the resolver reads (finding 3, inside round 2's fix).
4. **The YAML leaf check**, where "the word occurs in link's R/" stands in for "link reads this key" (finding 4, inside round 2's fix).
5. **Register values copied into printed strings, and into files no `where` names** (finding 5). I checked every copy against today's value and all agree, so this is fragility, not a wrong number.
6. Checked and clean: every `fn:` row whose function is called in the run. `knw_tune_run` passes its own seed, folds, n_boot, seeds_more, d_floor and prior_sd to `knw_tune_score`, `knw_tune_smoke` and `knw_tune_curve`, and those match the score and curve defaults the rows name. `knw_grade` is called with its quantile and class defaults; `knw_tune_repick` in 0320 with its `d_floor` default. `ext:` link CSV: `cluster_bridge_*` is 10000 / 0.05 on every row that clusters, NA elsewhere. `ext:` wet `routed_far_low` 0.2 at `94deeb5`, own-line condition as stated.
