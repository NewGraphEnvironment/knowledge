# PINE (Pine River) — past-reports table (report-discovery harvest)

Source: EcoCat keyword search on GNIS names (starting "Sukunka River" → 36 hits) + web search.

**Holistic coverage note (corrected):** all 307 Pine PSCIS crossings were assessed by **Crispin
Guppy in 2006–2007** and all carry a single EcoCat reference `[PSCIS71]` = Guppy's **Peace River
Stream Crossing Structure Inventory** (EcoCat id **11786**). So one inventory report *is* the PSCIS
input for the whole WSG — grabbing that one PDF covers 100% of the PSCIS side. The value of this
GNIS-name sweep is the reports **not** tied to PSCIS features: grayling life-history, watershed
restoration, and older barrier reconnaissance — whose **results sections are the real gold**.

EcoCat direct link form: `https://a100.gov.bc.ca/pub/acat/public/viewReport.do?reportId=<ID>`
(→ resolve to `documents/r<ID>/...pdf` → download → Zotero + Ragnar).
